Secure Device Control Guide

Complete Step-by-Step Instructions: Installation, Desktop Protection, Cloud Database Remote Control, and Employee Policy Restrictions.

Section 1 System Overview & Security Guarantee

Secure Device Control is an enterprise-grade hardware port and web endpoint security control suite designed for company PCs and employee workstations.

Zero Plaintext PIN Security Guarantee:
PINs are NEVER stored in plaintext anywhere on the PC or database. Every PIN is derived using Argon2id (16-byte random salt, 64 MB memory cost) and encrypted via Windows DPAPI bound to the SYSTEM account. Password extraction or offline database cracking is computationally infeasible.

Core Features Summary

  • Hardware Port Lock Down: Independent PIN-gated controls for USB Storage (Pendrives/External Hard Drives) and Mobile Devices (MTP/WPD smartphones).
  • Single-PC Email Licensing: Binds user Email IDs to individual PC machine names. The same Email ID cannot be used across multiple PCs.
  • Cloud Database Remote Control: Control web filtering modes, selective website whitelists, email restrictions, and port locks remotely for specific PCs from your Supabase PostgreSQL database.
  • Offline Log Buffering: All access attempts, PIN validations, and policy events are logged locally in SQLite offline and synced to Supabase when connected to the internet.

Section 2 Step-by-Step Installation & First-Time Setup

  1. Install the Windows Background Service:
    Run the installer or register the service executable on the employee workstation: 
    sc create "Secure Device Control" binPath= "C:\Program Files\SecureDeviceControl\SecureDeviceControl.Service.exe" start= auto
  2. Launch the Desktop App:
    Open SecureDeviceControl.Desktop.exe. Upon first launch, the app displays the First-run Registration & PIN Setup screen.
  3. Complete Registration Details:
    • User Email ID: Enter the employee's corporate email address (e.g., employee@company.com).
    • Device Unlock PIN: Enter a 6-digit PIN used to temporarily unlock ports or modify settings.
    • Uninstall PIN: Enter a separate 6-digit PIN used exclusively for uninstall authorization.
  4. Click "Initialize & Register":
    The service contacts your Supabase database to register the device and bind the Email ID to Environment.MachineName.
Single-PC Protection Enforcement:
If an employee attempts to initialize an Email ID that is already registered to another PC, setup will be rejected with an error: This Email ID is already registered to PC: 'PC-SALES-01'.

Section 3 Employee Desktop Application Usage

Once registered, the Desktop App presents the main control panel and live status indicators.

1. Desktop Status Indicators

Indicator Description
Service Status Shows Ready when protection is active, or Needs Registration.
Registered User & PC Displays the bound Email ID and local PC Machine Name (e.g., user@company.com (DESKTOP-BASIL-01)).
Pendrive / Mobile Lock Displays real-time lock status for USB Storage and Mobile Devices.
Unlock Timer Displays expiration time when a temporary unlock timer is active.

2. PIN-Gated Hardware Port Controls

Unlocking ports requires entering the 6-digit Device Unlock PIN. Locking ports down can be performed instantly without a PIN for immediate security.

  • USB Storage (Pendrive): Click Lock / Disable or Unlock / Enable.
  • Mobile Devices (MTP): Click Lock / Disable or Unlock / Enable.
  • Temporary 15-Minute Unlock: Click Unlock All for 15 min after entering the PIN to temporarily enable ports for file transfers. Ports automatically re-lock when the timer expires.

Section 4 Cloud Remote Control via Supabase Database

You can manage and update policies remotely for any specific PC individually right from your Supabase PostgreSQL database tables.

Supabase Policy Table Structure (device_policies)

Each registered PC gets its own dedicated row in device_policies keyed by email_id:

CREATE TABLE device_policies (
    email_id TEXT PRIMARY KEY,
    machine_name TEXT NOT NULL,
    web_filter_mode TEXT NOT NULL DEFAULT 'OFF', -- 'OFF', 'SELECTIVE', 'BLOCKLIST'
    allowed_websites TEXT NOT NULL DEFAULT '', -- Comma-separated (e.g., 'company.com, portal.company.com')
    blocked_websites TEXT NOT NULL DEFAULT '', -- Comma-separated (e.g., 'facebook.com, instagram.com')
    email_filter_mode TEXT NOT NULL DEFAULT 'OFF', -- 'OFF', 'RESTRICTED'
    allowed_email_domains TEXT NOT NULL DEFAULT 'company.com', -- Comma-separated
    updated_at TIMESTAMPTZ NOT NULL
);

How to Update a Specific PC Remotely

Execute SQL commands directly in your Supabase SQL Editor or edit rows in Table Editor:

Example 1: Enable Selective Web Access (ONLY Allowed Sites) for a specific PC:

UPDATE device_policies
SET web_filter_mode = 'SELECTIVE',
    allowed_websites = 'company.com, portal.company.com, supabase.com',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

Example 2: Restrict Email to Corporate Domain Only for a specific PC:

UPDATE device_policies
SET email_filter_mode = 'RESTRICTED',
    allowed_email_domains = 'company.com',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

Example 3: Turn Off Restrictions for an Authorized Administrator PC:

UPDATE device_policies
SET web_filter_mode = 'OFF',
    email_filter_mode = 'OFF',
    updated_at = NOW()
WHERE email_id = 'admin@company.com';

Remote Windows Sign-in Password Reset (windows_password_commands)

To reset or change a Windows sign-in password remotely from your database, insert a row into windows_password_commands:

INSERT INTO windows_password_commands (email_id, machine_name, target_username, new_password)
VALUES ('employee@company.com', 'DESKTOP-BASIL-01', 'JohnDoe', 'NewSecurePass#2026!');

The background service running under NT AUTHORITY\SYSTEM on the target PC will poll the pending command, update the Windows local user account password, and change the status in Supabase to COMPLETED within 30 seconds.

Remote Software Auto-Updater & Staged Beta Testing (software_updates)

To release a software update remotely, insert a record into software_updates with the version, download link, SHA-256 hash, and target machine:

Step 1: Test on a Specific Test Machine (Staged Beta Testing):

-- Pushes update v1.1.0 ONLY to your designated test PC 'DESKTOP-BASIL-01'
INSERT INTO software_updates (version, download_url, sha256_hash, target_machine)
VALUES ('1.1.0', 'https://github.com/Harsh854-22/DriverBasil/releases/download/v1.1.0/installer.exe', 'A3F982B7...', 'DESKTOP-BASIL-01');

Step 2: Deploy Globally to All PCs (Once Verified):

-- Pushes update v1.1.0 to ALL employee workstations automatically
INSERT INTO software_updates (version, download_url, sha256_hash, target_machine)
VALUES ('1.1.0', 'https://github.com/Harsh854-22/DriverBasil/releases/download/v1.1.0/installer.exe', 'A3F982B7...', 'ALL');

The background service downloads the update package over HTTPS, verifies its SHA-256 checksum, and executes the silent upgrade in the background.

Remote Software Uninstallation (remote_commands)

To remotely delete/uninstall the software from a specific employee PC, insert a row into remote_commands:

INSERT INTO remote_commands (email_id, machine_name, command)
VALUES ('employee@company.com', 'DESKTOP-EMPLOYEE-01', 'UNINSTALL');

The background service restores all hardware ports to unlocked states, removes web filter rules, logs a final audit event, and unregisters/deletes the Windows service cleanly.

VPN Software & Browser Extension Blocking (vpn_filter_mode)

To block employees from using desktop VPN software (NordVPN, ExpressVPN, OpenVPN, WireGuard) or browser VPN extensions (TouchVPN, Hola, ZenMate, Browsec), set vpn_filter_mode = 'BLOCKED' in device_policies:

UPDATE device_policies
SET vpn_filter_mode = 'BLOCKED',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

To grant VPN access back to an employee, update vpn_filter_mode = 'OFF' for their PC in your database.

Automatic Sync: Every employee PC background service polls Supabase every 30 seconds for policy changes and remote commands, and polls software_updates hourly for software releases.

Section 5 Selective Web & Email Domain Restrictions

1. Web Filtering Modes (web_filter_mode)

Mode Badge Behavior & Description
OFF OFF Web filtering is disabled. Standard browser access.
SELECTIVE SELECTIVE (Whitelist) Employees can ONLY access the selective websites listed in allowed_websites (e.g., company.com). All other websites on the internet are blocked.
BLOCKLIST BLOCKLIST (Blacklist) Blocks access to specific forbidden websites listed in blocked_websites (e.g. facebook.com).

2. Email Restriction Modes (email_filter_mode)

Mode Badge Behavior & Description
OFF OFF No email domain restrictions.
RESTRICTED RESTRICTED (Corporate Only) Blocks personal webmails (gmail.com, yahoo.com, outlook.live.com, temp-mail.org). Access is limited strictly to authorized corporate email domains listed in allowed_email_domains.

Section 7 Frequently Asked Questions (FAQ) & Troubleshooting

Q: What happens if an employee PC disconnects from the Internet?

The background service continues enforcing all hardware lock policies and web filtering offline using local SQLite storage. All activity logs generated offline are buffered in SQLite and automatically pushed to Supabase as soon as internet connectivity restores.

Q: How do I move an Email ID to a new PC replacement?

Run the following SQL query in Supabase to delete the existing registration record, allowing the employee to register on their new machine:

DELETE FROM registered_devices WHERE email_id = 'employee@company.com';

Q: Where are the local connection settings stored?

Service settings are located in c:\Users\admin\Desktop\DriverBasil\DriverBasil\src\SecureDeviceControl.Service\appsettings.json.
