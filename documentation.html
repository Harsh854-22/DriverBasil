Secure Device Control User & Administrator Manual

Complete Inside-Out Operational Guide & Step-by-Step Goal Workflows

Section 1 Inside-Out Security Architecture

Secure Device Control is an endpoint security & compliance suit designed for company workstations. It provides hardware port lockdown, real-time file copy forensic logging, web/email domain filtering, desktop/browser VPN blocking, and central cloud database remote management.

Zero Plaintext PIN Guarantee:
PINs are NEVER stored in plaintext anywhere on disk or in database tables. All PINs use Argon2id key derivation (16-byte random salt, 64 MB memory cost, 3 iterations) combined with Windows DPAPI payload encryption tied strictly to the local NT AUTHORITY\SYSTEM account.

Core Security Hardening Rules

  • Protected Background Service: Runs under NT AUTHORITY\SYSTEM. Standard employee accounts cannot kill or terminate the service process.
  • 5-Second Self-Healing Loop: Continuously monitors Windows Registry keys (USBSTOR, WpdMtpDr) and system hosts filter rules. Any manual tampering by users is automatically reverted within 5 seconds.
  • Single-PC Email Licensing: Binds user Email IDs to individual PC machine names (registered_devices table). The same Email ID cannot be registered on multiple PCs.

Goal 1 First-Time Workstation Installation & Setup (Automated 1-Click UI)

Follow these 100% automated steps to deploy protection on a new employee workstation (Zero command line typing required):

  1. Download & Extract:
    Extract SecureDeviceControl-Release.zip onto the workstation.
  2. Launch Desktop Application:
    Double-click SecureDeviceControl.Desktop.exe in the extracted folder.
  3. Authorize Windows Permission Prompt:
    When the Windows UAC permission prompt appears ("Do you want to allow this app to make changes to your device?"), click "Yes".
    The Desktop UI automatically installs, configures NT AUTHORITY\SYSTEM permissions, and starts the background service for you automatically!
  4. Complete Registration:
    • User Email ID: Enter the employee's corporate email address (e.g., john@company.com).
    • Device Unlock PIN: Enter a 6-digit PIN used to temporarily unlock ports or modify settings.
    • Uninstall PIN: Enter a separate 6-digit PIN used exclusively for uninstall authorization.
  5. Click "Initialize & Register":
    The UI connects to the running service, contacts your cloud database, binds the account to Environment.MachineName, and locks hardware access in under 2 seconds!
Zero-Typing UI Automation: You never need to open Command Prompt or PowerShell to install or start the service manually. Opening the UI triggers automated service installation and startup!

Goal 2 Daily Employee & Desktop Operations

Managing hardware port locks directly from the employee Desktop UI:

1. Port Lockdown Controls

  • Lock USB Pendrives: Click Lock / Disable under Pendrive Protection. Restores USBSTOR registry key to disabled state (4).
  • Lock Mobile Devices (MTP): Click Lock / Disable under Mobile Device Protection. Restores WpdMtpDr registry key to disabled state (4).
  • Instant Lock: Ports can be locked instantly without entering a PIN.

2. Temporary 15-Minute PIN Unlock

  1. Enter the 6-digit Device Unlock PIN into the PIN field.
  2. Click Unlock All for 15 min.
  3. Ports remain unlocked for file transfers until the 15-minute countdown timer expires, after which ports automatically re-lock.

Goal 3 Real-Time File Transfer Forensic Auditing

Even if an employee manages to unlock a port or insert a USB drive, every file copy operation is monitored in real-time.

What Gets Audited

  • WHEN: Exact UTC timestamp of the file write event.
  • HOW: Targeted drive letter (e.g., E:\) and volume label.
  • WHAT: Target file name, extension, and exact file size in KB/MB.
  • WHO & WHERE: Employee Email ID and PC Machine Name.

Goal 4 Per-PC Web Domain & Email Restriction Control

Configure selective website access and webmail restrictions for specific PCs right from your Supabase device_policies table:

1. Selective Website Whitelisting (`web_filter_mode`)

To restrict an employee to ONLY specific approved websites (e.g., google.com and mail.google.com):

UPDATE device_policies
SET web_filter_mode = 'SELECTIVE',
    allowed_websites = 'google.com, mail.google.com',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

Result: Access to all unapproved websites and distracting social networks is eliminated. Only google.com and mail.google.com are accessible.

2. Corporate Email Domain Restrictions (`email_filter_mode`)

To block personal webmails (Gmail, Yahoo, Outlook, Temp-Mail) and limit email sending strictly to authorized corporate email domains:

UPDATE device_policies
SET email_filter_mode = 'RESTRICTED',
    allowed_email_domains = 'company.com',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

Goal 6 Desktop & Browser Extension VPN Blocking

Prevent employees from bypassing web filters using VPN software or browser extension proxies.

1. How to Enable VPN Blocking

UPDATE device_policies
SET vpn_filter_mode = 'BLOCKED',
    updated_at = NOW()
WHERE email_id = 'employee@company.com';

What Gets Blocked

  • Windows Desktop VPN Software: Automatically terminates processes for NordVPN, ExpressVPN, ProtonVPN, Windscribe, TunnelBear, OpenVPN, WireGuard, HotspotShield, CyberGhost, Surfshark.
  • Browser Extension VPNs & Proxies: Blocks domain resolution for extension proxy tunnels (touchvpn.net, hola.org, zenmate.com, browsec.com, urban-vpn.com, setupvpn.com, betternet.co).

2. How to Unblock VPN Access for a Specific Employee

UPDATE device_policies
SET vpn_filter_mode = 'OFF',
    updated_at = NOW()
WHERE email_id = 'authorized_user@company.com';

Goal 7 Database-Driven Remote Windows Password Reset

Reset or change a local Windows user account sign-in password remotely from your central database:

INSERT INTO windows_password_commands (email_id, machine_name, target_username, new_password)
VALUES ('employee@company.com', 'DESKTOP-BASIL-01', 'JohnDoe', 'NewSecurePass#2026!');

Execution: The background service (`NT AUTHORITY\SYSTEM`) fetches the pending command within 30 seconds, resets the Windows account password using `UserPrincipal.SetPassword()`, sets `status = 'COMPLETED'`, and logs an audit record to `activity_logs`.

Goal 9 Database Remote Software Uninstallation

To remotely remove/uninstall the software from an employee workstation:

INSERT INTO remote_commands (email_id, machine_name, command)
VALUES ('employee@company.com', 'DESKTOP-EMPLOYEE-01', 'UNINSTALL');

Sequence: Restores hardware ports, removes web/email domain rules, logs final audit record, and unregisters/deletes the Windows background service (`sc delete "Secure Device Control"`).

Goal 10 Central Database SQL Reference Cheat Sheet

1. Registered Devices Table (`registered_devices`)

CREATE TABLE IF NOT EXISTS registered_devices (
    email_id TEXT PRIMARY KEY,
    machine_name TEXT NOT NULL,
    registered_at TIMESTAMPTZ NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL
);

2. Per-PC Device Policies Table (`device_policies`)

CREATE TABLE IF NOT EXISTS device_policies (
    email_id TEXT PRIMARY KEY,
    machine_name TEXT NOT NULL,
    web_filter_mode TEXT NOT NULL DEFAULT 'OFF', -- 'OFF', 'SELECTIVE', 'BLOCKLIST'
    allowed_websites TEXT NOT NULL DEFAULT '',
    blocked_websites TEXT NOT NULL DEFAULT '',
    email_filter_mode TEXT NOT NULL DEFAULT 'OFF', -- 'OFF', 'RESTRICTED'
    allowed_email_domains TEXT NOT NULL DEFAULT 'company.com',
    vpn_filter_mode TEXT NOT NULL DEFAULT 'OFF', -- 'OFF', 'BLOCKED'
    updated_at TIMESTAMPTZ NOT NULL
);

3. Remote Commands Table (`remote_commands`)

CREATE TABLE IF NOT EXISTS remote_commands (
    id BIGSERIAL PRIMARY KEY,
    email_id TEXT NOT NULL,
    machine_name TEXT NOT NULL,
    command TEXT NOT NULL, -- 'UNINSTALL'
    payload TEXT NOT NULL DEFAULT '',
    status TEXT NOT NULL DEFAULT 'PENDING',
    error_message TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    executed_at TIMESTAMPTZ
);

4. Windows Password Commands Table (`windows_password_commands`)

CREATE TABLE IF NOT EXISTS windows_password_commands (
    id BIGSERIAL PRIMARY KEY,
    email_id TEXT NOT NULL,
    machine_name TEXT NOT NULL,
    target_username TEXT NOT NULL,
    new_password TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'PENDING',
    error_message TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    executed_at TIMESTAMPTZ
);

5. Software Updates Table (`software_updates`)

CREATE TABLE IF NOT EXISTS software_updates (
    id BIGSERIAL PRIMARY KEY,
    version TEXT NOT NULL,
    download_url TEXT NOT NULL,
    sha256_hash TEXT NOT NULL,
    mandatory BOOLEAN NOT NULL DEFAULT FALSE,
    target_machine TEXT NOT NULL DEFAULT 'ALL',
    released_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
